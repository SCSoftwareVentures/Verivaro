# Reusable project export templates

Owner-only template revisions, immutable history, scoped owner/reviewer listing, stable project reference, active or retired version. The allowed presentation fields are heading, ordering and workbook inclusion; the approved underlying manifest and originals cannot be omitted. Exact current active revision checked before package assembly and final submission authorization. Version 4 index embeds the template identifier, version, reference, revision and validated configuration. Offline verification regenerates derived files; it verifies bytes against independently retained hashes, not the live template status or signing identity. TrustProof includes template version source digests and reconciliation. Limits: 32 templates, 16 revisions per template, 256 revisions per project. No tenant-global template library, arbitrary markup, cross-project sharing or external messages. Dedicated browser acceptance and grouped CI pending.
