# Human-confirmed OCR requirement provenance

An optional OCR import reruns recognition on authenticated original PNG bytes, checks the exact region digest and quote digest, and accepts only explicit author confirmation. The digest binds original-image hash, dimensions, OCR hierarchy, region coordinates, confidence and word count. A scoped immutable source row stores the server-derived location; it reuses the historical Office location column so prior TrustProof hashes remain unchanged. Normal requirement review cannot approve an OCR-derived version. A separate independent approval path requires matching original, quote and region digests, confirms the criterion and transcription together, denies authors and original image uploaders, and records a prefixed immutable review reason through the existing review table. Rejection remains available through the normal review path. No claim that a click proves visual comparison or that OCR is accurate. No automatic approval, no OCR correction claim; a changed recognition result requires a fresh preview. SQL trusts the authorized internal extraction adapter for image analysis, as with existing source imports. Browser requires affirmative author and reviewer actions; tests cover scope, tamper, audit continuity and generic approval bypass. CI pending. Remaining scanned PDF, correction workflow, accuracy benchmarks and production isolation validation.
