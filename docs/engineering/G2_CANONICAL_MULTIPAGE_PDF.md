# Canonical multi-page PDF evidence and ContractIQ provenance

The exact-reconstruction PDF allowlist now supports 1–32 pages, 1–40 ASCII text lines per page, maximum 90 characters per line and the existing 256 KiB upload limit. Canonical single-page bytes remain unchanged. A bounded stream reader reconstructs the entire PDF and verifies exact equality; arbitrary PDFs, compressed streams, attachments, image/scanned PDFs, active content and malformed object graphs remain rejected. Global line numbers are stable across all pages and the exact one-based page number is independently derived from authenticated original bytes, not the caller. Both existing extraction algorithms retain their historical identifiers. Migration 0056 expands the source constraint and both scoped SQL routines, without changing privileges; SQL checks feasible page/line ranges but trusts the authenticated application extraction adapter for actual bytes as before. Tests cover page limits, tampering, pagination, late page imports, actual encrypted ingestion/retrieval with PostgreSQL persistence and role denial. General PDF parsing and OCR are not claimed.
