# CustomerAccess scoped package access

An owner with a fresh independently reviewed and authorized snapshot can explicitly nominate an existing tenant viewer without active project membership. Grant identifiers are locators, not bearer credentials. Recipient preview gives only exact snapshot digest, project name, evidence count and expiry; retrieval uses a separate database function limited to that manifest's evidence IDs. The grant does not confer ordinary project access. Recipient, session, tenant access generation, all three original authorization generations, exact graph change stamp, expiry, revocation, archive and evidence integrity are verified on read and final assembly. Existing owner-only exports remain unchanged. Lifetime is at most 60 minutes and cannot outlive the original one-hour authorization. Read audit records indicate authorization checks, not delivery, acceptance or a signature. Revocation cannot undo data already downloaded.

Workspace owner can generate and revoke a grant; an authenticated recipient can preview and download via the scoped link or exact IDs. No automatic invitation or external notification; the recipient needs a tenant viewer identity. Snapshot approval remains mandatory. Dedicated browser validation, non-tenant recipients, reusable template storage and signed audit export remain outstanding. Integration acceptance added; current increment is unverified until CI.
