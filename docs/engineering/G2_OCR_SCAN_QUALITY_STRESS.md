# OCR image-quality robustness gate — synthetic

The baseline six-case CI benchmark is intentionally easy and must not be confused with real-world accuracy. This separate **real Tesseract** benchmark reads the independently rendered Valve V-204 fixture and applies five deterministic conditions: clean, low contrast, 5-pixel horizontal motion blur, black speckles, and row-dependent horizontal skew. It runs recognition through the authenticated offline OCR worker, parses bounded TSV, and reports **CER, WER, exact-line correctness, exact identifier recall and latency for each condition**.

All scenarios preserve mandatory independent human review; a low/high confidence score never releases an OCR requirement automatically. A degraded scan with zero recognised words still records a negative result instead of being silently dropped. No accuracy threshold is applied to degraded conditions because the expected success distribution is not yet measured on real documents. The test ensures safe execution, deterministic fixtures and per-condition reporting; test data is synthetic and contains no personal/customer records.

**Important limitation still unresolved:** Real-world measured accuracy needs user-authorised, consented and independently annotated samples across actual scanners/phones, document layouts, languages, font sizes, blur, shadow, skew and compression. A 5-condition synthetic matrix is not a representative validation set. Deployment readiness also requires memory/CPU-capped Linux PDF-conversion sandbox tests, authenticated quarantine ingestion, original-to-derived audit linkage, and end-to-end iPhone usability tests. No production deployment or cloud uploads.
