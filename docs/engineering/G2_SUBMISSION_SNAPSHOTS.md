# Submission snapshots (0037)

Immutable exact canonical PostgreSQL JSONB text (stored verbatim, hash SHA-256), full current criterion versions, source references, decisions, evidence hashes and metadata, project name/revision. Removes evaluation times and actor-specific hints. Package policy intentionally stricter than baseline preflight: every rule must be satisfied or independently confirmed not applicable, including optional rules, and at least one mandatory rule satisfied. No automatic omission of failed optional criteria. Preparer, separate reviewer and separate owner authorize exact digest. Current membership/actor generations, current graph, archived state, request age (7d), review age (24h), download authorization age (1h) are checked again at every approval/download. Approval is an internal authorization only, not a recipient delivery or certification. Only same authorizing owner downloads. Historical inspect retains exact manifest under current role scope. List hints are not guarantees of freshness. Package service reopens each source/evidence object through AEAD-verified retrieval and verifies exact digest/size/media type, creates fixed-name STORE ZIP with original manifest and checksummed package index; rechecks database authorization after assembly and before returning bytes. Max 64 unique objects / 16 MiB plaintext, two concurrent assemblies per process, 2 MiB manifest, global 1024 snapshots/64 MiB manifest storage, 16 per project. No external delivery, electronic signature, or certified recipient-specific workflow. Generation change or new graph revision requires a new snapshot; old archive is not mutated. Authorization linearizes at final database check; previously downloaded copies cannot be withdrawn. HTTPS and browser workspace expose preparation, exact snapshot inspection, independent review, owner authorization and authorized ZIP download. Mutation routes require same-origin POST; download uses no-store attachment and actual ZIP SHA-256. Runtime timeout may terminate slower large assemblies safely. No live recipient delivery.
