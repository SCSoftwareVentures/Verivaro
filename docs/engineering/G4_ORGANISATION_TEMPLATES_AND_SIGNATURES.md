# Organisation template reuse and signed checkpoints

Explicit owner publication of a current active project template revision exposes only the presentation fields in a tenant-scoped owner catalog. Withdrawal, source retirement, supersession or source archive removes it from new imports. Import creates independent local revisions and immutable provenance; previous imported copies are not revoked or synchronised. No source evidence or project membership is shared. Publication and import add two TrustProof types. The catalog and import are available through an active owned project only.

Optional application config {"auditSigning":{"keyFile":"/absolute/private/ed25519.pem"}} enables separate Ed25519 signing (never commit private keys). Signer requires full contiguous verified chain, stable head, current scoped access for every page and final recheck, up to 8192 entries per issuance. Signed payload binds tenant, project, head, counts, application timestamp and public-key fingerprint. Exported PEM is informational; offline verification requires independently trusted public key. No independent timestamp or external key custody; deployment provisioning, rotation policy and large-chain streaming remain outstanding. Unit, HTTPS and browser tests added; no claim of verified workflow results for this revision.
