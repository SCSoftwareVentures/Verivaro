# Browser usability regression

The actual repository workspace assets are exercised in headless Chromium and WebKit, with synthetic API responses, at viewport widths 320, 390 and 1280 CSS pixels. Checks signed-out and first-invitation screens, validation and code clearing, owner controls, escaped project names, report links, authenticated rename request and idempotency key, archived state, dynamic loss of permissions and session expiry, with no horizontal overflow or uncaught script errors. Production API behavior is covered separately by the TLS/PostgreSQL integration gate; this browser test does not simulate a real provider, payment, or production infrastructure. WebKit is not physical iPhone Safari. No external application deployment, paid service, screenshots or browser traces uploaded. Browser test tooling is exact-version Playwright in a temporary runner directory, not a production dependency.
