# Strict multipage scanned-PDF ingest

Adds a separate allowlisted **2–4-page** image-only RGB PDF layout with a single image XObject per page, exact page order/object graph, fixed draw commands, verified byte offsets and no extra objects or annotations. PDF size <=256 KiB; up to four 2048-by-2048 pages, maximum 2,097,152 pixels across pages. Each compressed stream is decoded with strict bounded zlib consumption and converted to ephemeral PNG. Original bytes stay encrypted; page-selected raster digest and source PDF digest bind each OCR region. No raw arbitrary PDF is admitted; mixed-content, password-protected, annotated, JavaScript-containing and generic scanner-produced PDFs remain unsupported. Existing single-page PDF bytes and OCR anchors are unchanged. Server validates selected page and re-derives original region upon import. Browser allows page selection and no automatic OCR approval. Synthetic multipage unit/integration, tamper rejection, Chromium/WebKit and independent Poppler rendering tests added. Security migration permits OCR page numbers 1–4 only. This remains distinct from general-purpose PDF conversion; broader support must use an independently isolated sanitizer without loosening upload admission. Cost $0, no merge or deploy.
