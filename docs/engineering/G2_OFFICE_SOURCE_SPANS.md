# Strict Office source-span extraction

Added a dependency-free, bounded XML subset and exact-schema DOCX/XLSX readers using the Office ZIP preflight. The supported DOCX profile is content-only body paragraphs with literal runs; unsupported formatting, tables, fields, alternate content, and additional parts are rejected. The supported XLSX profile uses literal inline/shared strings and raw numeric values, up to 16 sheets, 1024 rows and 52 columns, and recognizes Verivaro's inert register layout; formulas, styles, hidden sheets/rows, drawings, arbitrary extra parts, external relationships and unsupported XML fail closed. Content types, exact relationship targets, unique names and IDs, ordered cell coordinates and every package part must match the allowed schema. XML processing has no network or filesystem access and rejects DTD, entity declarations, processing instructions, invalid characters, duplicate attributes and excessive depth/nodes. Extracted decoded quotes retain original archive SHA-256, part SHA-256, paragraph or sheet/cell location, and quote SHA-256. Raw numeric values are not Excel display values. This is a restricted parser, not general Office compatibility. Unit tests cover exact text and malicious/ambiguous input. Office ingestion and persistent graph imports remain disabled pending endpoint, encrypted storage, provenance schema and full end-to-end tests. CI pending.
