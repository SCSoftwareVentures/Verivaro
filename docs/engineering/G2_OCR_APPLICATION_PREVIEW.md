# Application OCR preview

Optional strict application config `"ocr":{"socketPath":"/run/verivaro-ocr/worker.sock","keyFile":"/absolute/app-owned/raw-32-byte-ocr-key"}` requires existing encrypted ingestion, an independently provisioned raw key distinct from other application keys, and the isolated worker. No automatic enablement or changes to old configurations. The authenticated graph API accepts POST OCR preview requests only for evidence ID and original SHA-256; existing origin, admission, session and tenant/project guards apply. Preview checks active write authorization before and after recognition and denies archived projects. Client uses the authenticated Unix transport and is closed on shutdown/startup failure. Browser panel renders unverified region text as textContent only, engine scores, original attachment download and pixel coordinates; never creates a requirement, saves OCR text or interprets confidence as probability. Preview clears on refresh/scope change and is hidden for archived/non-writable projects or absent capability. Chromium/WebKit synthetic regression plus archived unit case added. No live worker deployment or infrastructure changes. CI pending.
