# G2 rejection preflight (0036)

The scoped graph assessment now rechecks exact source and linked encrypted object metadata and ciphertext digests, using a materialized inventory of distinct referenced objects to avoid hashing the same object for each link. Corrupt or missing metadata, mismatch, or source quote digest inconsistency blocks assessment irrespective of optional/mandatory applicability. This is database envelope-integrity screening, not full AEAD decryption or independent attestation. A rejected criterion is explicitly distinguished from pending review. The authorized HTTP assessment response includes a deterministic remediation queue, blocker counts, optional advisories, floored mandatory coverage (null when no mandatory rules), and suggested responsible roles. The adapter refuses inconsistent summaries, unknown states and invalid identifiers. Duplicate case-folded/NFC/whitespace-normalized criterion text and different applicability, repeated byte hashes, and use of source as evidence generate advisory hints, not semantic conclusions. No AI or external service, no automatic approval, correction, deletion, merging or legal prediction. No project-wide release gate yet. The browser shows prioritized remediation, links to the affected criterion and explicit limitations; archived projects remain historical/read-only. Existing passed rule decisions are historic attestations. CI exercises storage corruption and restoration on a disposable database only, graph and HTTPS regression, pure unit cases and browser fixtures.
