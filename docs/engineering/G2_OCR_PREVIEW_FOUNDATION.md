# Bounded OCR preview foundation

Added dependency-free validation of Tesseract TSV output, hierarchical row consistency, strict image bounds, bounded input/output and counts, per-line bounding boxes, mean/minimum word confidence and quote SHA-256. OCR confidence is not calibrated probability. An injectable read-only preview verifies authorization, immutable original PNG hash and type, rechecks write scope after extraction, and clears original and engine output buffers. No import or persistent OCR evidence is permitted. A local Tesseract English CLI adapter uses stdin/stdout, no shell, fixed arguments, no inherited credentials, one active request, bounded time/output, cancellation and child termination. It is intended for a separate restricted worker account; it is not enabled in the web process. CI includes adversarial unit tests and an actual offline Tesseract probe on independently rendered synthetic PDF text converted to strict PNG. No cloud API, actual user documents, extra subscription or production deployment. Remaining: independently enforced worker isolation/resource limits, authenticated local socket, application runtime/UI opt-in, persistent human-confirmed source provenance, broad OCR accuracy evaluation and scanned PDF support.
