# Bounded FlateDecode and PDF literal compatibility

The canonical text-PDF allowlist now accepts exact-length zlib/FlateDecode content streams at different compression levels, alongside unchanged legacy plain streams. Only the existing exact object graph, text operators, page order, font and xref layout are accepted; the entire byte sequence is reconstructed using original compressed bytes. PDF literal parentheses and backslashes are escaped and decoded deterministically, and printable ASCII punctuation is supported. Limits: 256 KiB original, 32 pages, 40 lines/page, 90 characters/line, 8 KiB expanded page stream, bounded compressed stream, no trailing compressed members, encryption, scripts, alternate filters, attachments or arbitrary PDFs. Original bytes remain immutable; exact decoded quote, page and global line are independently re-derived on import. Tests cover multiple compression levels, tampering, expansion limits, appended members, unexpected operators, escaping and encrypted PostgreSQL ingestion/extraction. This is a narrowly allowlisted PDF subset, not a general PDF parser or OCR. CI pending.
