# G1 database foundation (draft)
Initial PostgreSQL 16 schema for tenant, identities, tenant and project membership, projects, immutable-intended document and requirement revisions, source spans and evidence links. Composite FKs constrain references to the same project and tenant. RLS forced on each table; no runtime write privileges, direct membership or key access, or document/evidence reads. The only granted business read is project metadata, scoped to a short-lived HMAC-authenticated transaction-bound context and active membership versions.

The signed context format is a JSON UTF-8 string containing tenant, project, actor, tx (pg_current_xact_id textual value), key UUID, exp epoch seconds, member_version and project_version. HMAC-SHA256 over the exact raw bytes; keys must be provisioned privately. The trusted signer and API must establish authenticated actor identity and membership, never sign caller claims. No production keys are created by this migration. The CI test harness signs only fictional claims using an ephemeral key. Context is checked per statement; live revocation behavior under transaction isolation and pooled connections requires API tests. The role is NOLOGIN until a restricted login is provisioned separately.

Initial CI uses an ephemeral PostgreSQL 16 service with a non-production fixture password and SET ROLE tests. Exact production image digest, isolated login tests, key rotation, constant-time signature comparison strategy, revocation, API auth and scoped write procedures remain outstanding. The HMAC verifier uses database byte equality (not asserted constant-time). Source spans store code-point offsets; domain uses UTF-16; translation must be verified before connecting the layers. No claim of immutable enforcement for privileged writers, scanner integration, current-version pointers, or valid evidence semantics. Runtime reads of evidence stay denied pending those contracts.

Gate G1 remains open. No real data, external providers, release approval, or production deployment. Existing 43 unit tests remain unchanged.
