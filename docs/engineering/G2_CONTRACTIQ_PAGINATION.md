# ContractIQ paginated source review

Extraction remains bounded to 64 eligible original source lines per response. The optional integer `afterLine` cursor (0–262144) is exclusive and bound by the authenticated evidence ID and digest supplied on every request. `nextAfterLine` is null when no later eligible line remains; matched/skipped counts describe the entire source. Each page rechecks write access, original digest, strict evidence format and extraction capacity. The browser provides first/next navigation. Import independently locates the exact requested original line, verifies its quote digest and retains its original algorithm and page; candidates beyond the first response can now be drafted. Independent review remains mandatory. No arbitrary PDF, OCR, semantic extraction or legal interpretation is introduced. Tests cover cursor boundaries, skipped lines, complete traversal, late imports, mismatched quotes and browser navigation. CI verification pending.
