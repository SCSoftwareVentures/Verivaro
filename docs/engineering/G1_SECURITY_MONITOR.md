# G1 security monitoring and incidents

Aggregate admitted request results in a bounded 60-slot minute ring, with no raw IP, token, artifact identifiers or document contents. A successful lease finish atomically consumes the lease and records one outcome; duplicate or foreign release adds nothing. Existing release wraps finish with unknown outcome. Gateway classifies admitted authorization denials, delivery errors, integrity failures and completed response writes (not recipient receipt). Pre-admission rejected traffic is not counted by this telemetry; capacity pressure includes the current admission counter, leases and reserved bytes.

Restricted monitor evaluator detects 10 authorization denials or 10 delivery failures across the current and previous four minute buckets, any integrity failure, any lease older than two minutes, or instantaneous resource pressure above 80% of configured slots/bytes/current-window rate. These are initial engineering thresholds, not production-calibrated. Incident events are append-only; one active incident per kind, acknowledgment and explicit closure by separate operator role, escalation after five minutes critical or fifteen minutes warning if not closed. Persistent signals reopen manually closed incidents at next evaluation. No automatic release, account restriction or external notification. Snapshot health includes last successful evaluation; stale heartbeat indicates evaluator problems only when checked independently.

Deployment must invoke evaluate() about once per minute from a restricted worker with connection/statement limits and monitor its heartbeat independently. Operator must review and resolve root cause before closing. Monitor has no access to business records or credentials. Acknowledge/close events identify the DB login; provision unique operator credentials. Alert routing, external delivery, actual scheduled service, retention of audit events, calibration, broader identity/storage/edge telemetry and production validation remain outstanding. No paid infrastructure.
