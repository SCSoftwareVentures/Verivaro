# Manual exact-source review

An explicit manual selection mode pages through non-empty source lines, including text missed by deterministic obligation cues. It never labels a line an obligation. Each import derives the quote and page from the authenticated original, checks the supplied quote hash and saves a separate immutable `manual-source-line-v1` provenance identifier. Existing one-source-line uniqueness prevents duplicate requirements from the same original line. Independent review and applicability controls remain mandatory. Both plain text and supported PDF subsets use the same 64-candidate page bound and existing access controls. The UI defaults to heuristic suggestions; manual mode is opt-in and cleared on scope change. Tests cover non-modal lines, blank lines, forged hashes, actual persistence, duplicates and browser navigation. No arbitrary PDF/OCR or external model is introduced. CI pending.
