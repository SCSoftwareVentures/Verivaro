# ContractIQ source-linked extraction (0035)

Deterministic modal-word line extraction from authenticated, hash-verified encrypted UTF-8 text and the existing exact canonical single-page PDF subset. No external AI, OCR, general PDF, legal interpretation or claim of exhaustive extraction. Candidate matches retain negation and original trimmed line, deterministic line ordinal (page 1 for canonical PDF), whole-file SHA-256 and quote SHA-256. Cap 64 returned candidates, disclose truncation and skipped excessively long/control-bearing lines. User explicitly selects a candidate and its applicability; the server independently re-reads authenticated bytes and derives quote, never trusts browser-supplied criterion. Database records exact source object, version and quote hash atomically; duplicate source line conflicts. Trusted runtime attests line derivation; DB verifies scope/hash/quote digest, not decrypted plaintext. Independent rule review still required, and imported source is not itself proof of satisfaction. Later manual revisions do not inherit source attribution or reviews; historical source remains immutable. Full source review required: modal-word heuristic can produce false negatives/positives, and multiline obligations are not reconstructed. Archived projects deny imports; access checks and audit use existing retrieval service. Source metadata and selected quote are subject to project privacy and encrypted backups. No production provider or external service fees.

Browser workspace exposes a bounded candidate preview, explicit applicability selection and deliberate source import; archived projects and non-writers cannot use it. Existing source-linked rule displays immutable document ID and line/hash references. Browser regression exercises the preview/import path at all three viewport widths.
