# Offline OCR quality benchmark — G2

Adds **six synthetic engineering-document phrases** rendered to PDF using the existing canonical text exporter and independently rasterized by Poppler. Recognition is performed using the actual Tesseract English engine through Verivaro's authenticated Unix socket. A pure, unit-tested scorer reports Unicode NFKC / whitespace-normalized **character error rate (CER)**, **word error rate (WER)**, exact-line rate, exact numeric/ID token recall, and per-case/p50/p95 recognition latency in milliseconds. No OCR confidence is interpreted as a calibrated correctness probability. Scores are aggregated by total reference characters/words, not averages of percentages.

**Regression gates for these six easy synthetic fixtures only:** CER <=10%, WER <=20%, exact-line rate >=66%, and ID/number recall >=80%. There is no hard throughput or latency claim. Latency is observed and printed but not used as a CI rejection threshold. These thresholds are guardrails against a blatant engine/configuration regression, **not verified production accuracy targets**, customer acceptance evidence or an industry benchmark. One locale, one font, one DPI, one engine setting, and clean text are insufficient to evaluate smartphone photos, skew, blur, shadows, handwritten annotations, page layout, multi-language documents, confidentiality or compliance-document validity.

**Commercial validation still outstanding:** a consented, legally obtained, independently annotated document corpus, stratified by document type, scan quality, page count, language and hardware; measured per-stratum CER/WER and critical-data errors, resource/cost and manual review time; false extraction analysis; and operating cutoffs based on consumer consequences rather than synthetic convenience. No user documents are stored or sent to a cloud OCR API. This benchmark is additional evidence, not a substitute for existing independent human confirmation. Review branch only, no deployment or external spending.
