# Authoritative document conditions

An applicable pending criterion authored by the current submitter can bind a current independently reviewed certificate, warranty or inspection metadata revision with exact document, equipment, issuer and source digest. The ordinary independent rule and evidence link assessments are still required: the typed condition specifically needs a pass on the pinned original. Unknown dates, future issue, expiry, mismatch, integrity failure or metadata supersession cannot be treated as a satisfied typed criterion. The local assessment applies the condition before dependency fingerprinting; existing submission freshness and customer graph stamp incorporate the result. A later applicable criterion revision cannot silently omit a historical typed condition. Independently reviewed not-applicable is not automatic waiver.
