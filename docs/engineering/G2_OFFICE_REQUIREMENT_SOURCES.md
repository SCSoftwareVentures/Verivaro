# Persistent Office source provenance

Office source spans are now available in ContractIQ manual and heuristic modes. Every draft is reconstructed from authenticated original bytes; ordinal, decoded trimmed quote digest, XML part digest and paragraph or sheet/cell coordinates are derived server side, not accepted from the browser. Shared strings retain their second part digest/index. Migration 0059 extends the existing append-only requirement source table with Office-only location data and scoped import function. Historical source row JSON and customer graph stamps omit the new null field, retaining prior digests; new Office rows include location in TrustProof and graph fingerprints. SQL validates location shape and binds the immutable evidence hash; it trusts the authenticated extraction adapter for exact source bytes as before. Office upload integration test coverage is moved after the schema supporting Office MIME types. Existing role, archive, duplicate-source and independent-review controls remain. CI pending. General-purpose documents and OCR remain unsupported.
