# Indexed handover and portable register foundations

The original v1 package remains supported. Two fixed versioned profiles (handover-v1 and register-v1) add a paginated PDF cover/index, requirement CSV and evidence CSV to the exact approved original attachments. The profiles order the PDF differently; file paths are fixed and safe, all file digests are reconciled, formula-like CSV values are quoted and neutralised, and the original manifest holds exact source values. The offline verifier supports both v1 and v2, reconstructs derived files and checks the canonical STORE archive against externally trusted digests. Same existing authorisation, current graph and final freshness checks apply. No blocked draft is exported as ready; no signature or delivery claim. PDF non-ASCII is displayed as codepoints; original text remains in JSON/CSV.

ZeroSwitch standalone bounded UTF-8 CSV preview accepts explicit header mappings and separates invalid/duplicate rows, with no database writes or formula evaluation. Dedicated import UI, draft creation, XLSX, mutable custom templates, blocked-watermarked draft cover, fuller archive export, hardware and browser acceptance remain outstanding. Unit and HTTPS tests added; grouped CI review is pending.
