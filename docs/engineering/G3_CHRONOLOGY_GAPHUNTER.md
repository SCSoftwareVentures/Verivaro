# Project intelligence archive and GapHunter

Owner-only event creation, independent source review, immutable bounded records and current project scoping. Exact snapshot hash required for asserted submission, delivery, receipt, acceptance and rejection. Unknown claimed event time remains unknown; server recording time is separately labelled. Contradictory assertions are preserved as review hints. System preparation, review and export authorisation do not imply delivery. Source support is not a finding of legal validity or actual acceptance.

GapHunter ranks current issues by mandatory/safety status, schedule urgency, independently reviewed financial relevance and remediation category. Amounts are referenced, not summed across deficiencies. Repair categories are heuristics, not cost/time estimates. Owner-only JSON export contains chronology, financial history, snapshot metadata, hashes and deficiency list, with exact-byte attachment digest. It is not a signed archive, original-file bundle, full tenant export or recipient-authenticated acknowledgement. Archive export currently requires active owner write permissions. Formal receipt/acceptance by recipients, evidence attachment bundles, assignment and resolution, and dedicated browser acceptance remain outstanding.
