# Independently verifiable deletion-evidence copy and recovery

A separately configurable, public-key-only deletion-evidence replica now mirrors each Ed25519-signed `prepared` and `completed` receipt. It accepts only authentic, correctly scoped, correctly chained statements; O_EXCL/0600 write, fsync of file and directory, and exact readback are mandatory. The signer-side ledger verifies that both copies are identical on every read. The encrypted original **cannot be unlinked** unless preparation has succeeded in both stores. Post-unlink completion is likewise mirrored before the local tombstone is promoted. Missing, truncated or tampered copies fail closed; the system never synthesizes a successful deletion from a partial record. A separate verifier can validate surviving archived receipts using only the independently trusted public key even after the signer-side directory is lost, but any attempted automated restore or deletion retry is denied pending operator reconciliation.

**Scope limitation:** separate directories are not independently managed offsite storage. For true recovery assurance the replica root must be on separately managed, write-protected storage (or exported through an independently authenticated backup service), with a documented retention policy and tested recoveries. The software tests two independent directories; it does not claim physical or geographically separate backup. Keys are never generated, installed or sent to production. No public endpoint, scheduled deletion, merge or deployment.
