# Archive succession and account invitations (0032)

Tenant succession retains existing three-party authorization. The operator completion locks project rows and creates immutable per-archive handover receipts bound to the exact transaction ID, transfer request, outgoing owner generation, incoming actor, prior membership generation and frozen archive revision. The archive guard only permits this exact successor-owner membership transition before the transfer receipt is committed. Ordinary membership assignments and all existing archive write protections remain. Outgoing memberships revoked, no reopening, evidence modification, export reactivation or new shares. Copies only current, unexpired owner assignments. Historic archive record and evidence unchanged. Trusted DBA remains outside the service security boundary.

An existing owner enrollment request can instead be approved as an invitation by the dedicated operator, who verifies the provider subject out of band and supplies a cryptographically random 32-byte base64url code and case UUID. Only a digest is stored. The operator can provision an exact new provider binding without tenant membership; an invited actor can sign in, but has no tenant access until authenticated redemption. Redemption requires matching request, tenant, actor, digest, live session and active provider binding; original owner's session/generation must still be current. Expiry is the earlier of 15 minutes from request and owner session expiry. Owner can cancel before redemption. Atomic exact replay returns historic generation only while that membership remains current; cannot reenroll after revocation/role change. No emails, automatic messaging, public code URLs or external IdP-account creation. Operator communicates tenant UUID, request UUID and code privately; new browser panel is accessible to signed-in actors with zero workspaces. Direct enrollment remains available for explicitly operator-approved requests without an issued invitation. Unredeemed new bindings remain sign-in-only; operator can disable them via existing lifecycle on request. Restore quarantine blocks redemption and handover. Browser engine and actual external identity-provider checks remain outstanding.
