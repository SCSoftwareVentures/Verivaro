# EvidenceRescue bounded batch intake

Select multiple files or a directory where the browser supports directory selection. Preview every selected item, exact digest, unsupported status and duplicate bytes in that selection. Limit 12 files per batch, original immutable upload limit 256 KiB each. Each supported original uses the existing scanned encrypted ingestion path and an independent request UUID. Retain duplicate originals and separately record supplied filename and relative label with exact uploader/request/digest binding. No path is used as a filesystem path. Import results show whether bytes are stored and lineage committed. On a lost response retry the same in-memory request ID; pause on rate limits or conflicts, do not silently skip. Upload and lineage are separate transactions, so storage without lineage can occur on interruption; UI explicitly shows pending lineage and permits same-page retry. No cross-project/tenant deduplication or byte collapse; existing scoped duplicate analysis identifies same-byte records. Lineage list shows most recent 100 project records; TrustProof covers all recorded lineage. No persistent local batch queue, ZIP extraction, automatic evidence approval, arbitrary Office/PDF adapters, or full blueprint capacity. Browser/unit/HTTPS tests added, verification pending.
