# ProofLock authenticated workspace

Adds authenticated same-origin GET /verification/prooflock and strict POST milestone-write, window-propose, window-review with existing session, admission and scope checks. Invalid local times/offsets or unknown schedules with dates are rejected at the HTTP boundary and rechecked by the persistence layer. The browser renders deadlines, priorities and historical revisions from the server rather than inferring approval from local state. It supplies explicit timezone/offset, uses retry IDs and expected revisions, renders untrusted text safely, and disables mutation controls on archived projects. The current role hints are not individual authorization; database independence and current identity checks remain authoritative.

Browser fixtures exercise milestone creation, proposal, independent approval and a revision to unknown at mobile and desktop widths, while live HTTPS tests exercise malformed inputs, revoked sessions, independent review and stale-revision denial. The view remains advisory. No email, alerts, payment actions, offline capture, signed timeliness proof or external deployment. Explicit capture context, actual mobile photo ingestion, alert deduplication and controlled window amendment remain separate increments. CI must pass before claiming integration verified.
