# Custom handover and reviewable remediation

The configured export uses version 3 package metadata with an immutable embedded version 1 configuration. Allowed fields are presentation heading, index order and workbook inclusion. Mandatory originals, canonical manifest and PDF/CSV registers cannot be removed or renamed. No arbitrary output paths, executable templates or remote assets. Offline verification regenerates all derivatives. Configuration is per download, not a persisted reusable template library.

AutoCorrect displays a deterministic correction checklist based on current preflight issues. It never edits evidence, certificates or criteria. SmartChase consolidates exact-version assigned contributor follow-ups by recorded actor identifier, routes ambiguous or reviewer/operator matters to manual review and never sends messages. The workspace shows drafts only. No external recipient addresses, scheduled notifications, automatic communications or delivery status. Current recipient access must be checked before external reuse. Dedicated browser acceptance, persisted custom template library, saved correction decisions and provider-based delivery remain outstanding. Unit and HTTPS tests added.
