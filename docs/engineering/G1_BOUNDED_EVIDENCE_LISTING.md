# Bounded evidence metadata listing

CI #162 and #168 exposed intermittent evidence-listing failures; #168 recorded a server statement timeout. Migration 0030 introduces a narrowly scoped indexed read, with one signed transaction-context/current-session and live tenant/project membership authorization per statement, followed by a fixed 200-row metadata projection. Denies missing/revoked/expired membership, disabled actor, wrong tenant and invalid context. No ciphertext, storage ref, or raw evidence data available through the function. Forced RLS remains for direct access. Runtime selects the new function; historical staged tests keep the original adapter query. The production runtime requires current migration. Align transaction statement timeout (5s) below pg client query timeout (6s), and destroy uncertain connection without queueing rollback behind timed-out work. Bounded stage+SQLSTATE or classified driver timeout diagnostics never contain raw error messages or bind parameters. Regression includes 240 seeded rows, exact bounded IDs and unauthorized empty results. Root cause of historic performance variability not definitively isolated, but this removes repeated per-row RLS authorization from the application hot path. No production scale claim.
